# 爱心轨迹（文字框版）❤

一个用 Python 标准库 `turtle` 写的小程序：运行时，一只光点会沿爱心轨迹移动，
沿途铺下一枚枚文字框，框里轮流显示这些祝福语：

> 多喝水 · 好好爱自己 · 好好吃饭 · 保持好心态 · 拒绝内耗 · 顺顺利利 · 别熬夜

## 效果

- 深色背景 + 淡淡的爱心轮廓作为「轨迹」
- 彩色胶囊文字框沿轨迹依次出现
- 光点沿爱心移动，铺满后停留展示

## 运行

无需安装任何第三方库，Python 3.8+ 即可：

```bash
python heart_track.py
```

## 自定义

打开 `heart_track.py`，顶部有可以调整的参数：

| 变量 | 含义 |
| --- | --- |
| `PHRASES` | 文字框里的祝福语列表 |
| `BOX_COUNT` | 文字框数量 |
| `FONT_SIZE` | 文字字号 |
| `HEART_SCALE` | 爱心整体大小 |
| `BOX_COLORS` | 文字框配色 |
